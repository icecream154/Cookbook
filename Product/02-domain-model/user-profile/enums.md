# 用户与饮食画像域：标准枚举字典（`ENUM-USR-*`）

## <a id="enum-usr-purpose"></a>1. `ENUM-USR-Purpose`（使用 APP 目的）

| 枚举编码 | 标准展示文案 | 排序 | 业务判定语义 |
| :--- | :--- | :--- | :--- |
| `daily_decide` | 解决每天吃什么 | 1 | 默认预选项；强调每日三餐不重样与换一换便捷度 |
| `learn_cooking` | 零基础学做菜 | 2 | 提升含精细视频节点与新手简单难度菜谱权重 |
| `weight_fitness` | 减脂增肌控卡 | 3 | 卡片优先外显单人份千卡与高蛋白/低卡标签 |
| `family_care` | 照顾家人营养三餐 | 4 | 强调荤素汤羹均衡搭配与老小适口性 |
| `explore_gourmet` | 探索各系美食 | 5 | 提升多元地方菜系与异域料理曝光多样性 |

---

## <a id="enum-usr-householdsize"></a>2. `ENUM-USR-HouseholdSize`（期望用餐人数档位）

| 枚举编码 | 对应人数数值 | 标准展示文案 | 业务判定语义 |
| :--- | :--- | :--- | :--- |
| `solo` | `1` | 1人食 | 午晚餐优先配 1 道一碗端或荤素合炒，减少洗碗与剩菜 |
| `couple` | `2` | 二人世界 | 未建档游客默认兜底档位；午晚餐按一荤一素搭配 |
| `family_3` | `3` | 三口之家 | 午晚餐按两菜一汤搭配，开放儿童/老人勾选项 |
| `family_4_plus` | `4 ~ 8`（默认 `4`） | 四口及以上 | 午晚餐按三至四菜一汤搭配，支持步进器微调具体人数 |

---

## <a id="enum-usr-flavor"></a>3. `ENUM-USR-Flavor`（风味喜好）

| 枚举编码 | 标准展示文案 | 业务判定语义 |
| :--- | :--- | :--- |
| `savory` | 咸鲜家常 | 百搭家常基础风味 |
| `sweet_sour` | 酸甜开胃 | 茄汁、糖醋、荔枝口等风味 |
| `spicy_fragrant` | 香辣下饭 | 干香微辣、湘赣小炒等风味 |
| `mala` | 川渝麻辣 | 含花椒麻感与红油豆瓣风味 |
| `light_fresh` | 清淡原鲜 | 白灼、清蒸、上汤等凸显食材本味 |
| `rich_sauce` | 浓郁酱香 | 红烧、酱焖、照烧等浓油赤酱风味 |
| `exotic` | 咖喱/异域风味 | 日韩、东南亚咖喱、西式香草奶油等风味 |

---

## <a id="enum-usr-avoidtag"></a>4. `ENUM-USR-AvoidTag`（高频忌口与过敏大类）

| 枚举编码 | 标准展示文案 | 业务判定语义 |
| :--- | :--- | :--- |
| `cilantro` | 香菜 | 排除所有含香菜（芫荽）的菜谱，或在检索详情提示可省 |
| `scallion_garlic` | 葱姜蒜 | 排除以葱/姜/蒜/洋葱/韭菜为核心辅料的菜谱 |
| `seafood` | 海鲜水产 | 排除鱼、虾、蟹、贝类、虾皮等水产食材 |
| `beef_mutton` | 牛羊肉 | 排除牛肉、肥牛、牛腩、羊肉等食材 |
| `offal` | 动物内脏 | 排除猪肝、肥肠、鸡胗、毛肚等内脏食材 |
| `peanuts_nuts` | 花生坚果 | 过敏高危项，严格排除花生、腰果、核桃、芝麻酱等 |
| `dairy` | 乳制品 | 排除牛奶、黄油、淡奶油、芝士奶酪等乳源食材 |

---

## <a id="enum-usr-skilllevel"></a>5. `ENUM-USR-SkillLevel`（做菜能力等级）

| 枚举编码 | 标准展示文案 | 辅助引导副标题 | 允许自动推荐的最高菜谱难度 |
| :--- | :--- | :--- | :--- |
| `beginner` | 厨房小白 | 切配简单、调料精确到勺/克 | 仅限 `easy`（简单） |
| `intermediate` | 家常熟手 | 掌握日常煎炒炖煮（默认） | `easy`（简单）、`medium`（适中） |
| `advanced` | 料理达人 | 可挑战复杂火候与宴客硬菜 | 不限难度（含 `hard` 进阶挑战） |

---

## <a id="enum-usr-timebudget"></a>6. `ENUM-USR-TimeBudget`（平日期望单餐耗时）

| 枚举编码 | 分钟上限值 | 标准展示文案 | 业务判定语义 |
| :--- | :--- | :--- | :--- |
| `t_15` | `15` | ≤15分钟极速 | 优先召回快手小炒、焖面三明治等极速菜 |
| `t_30` | `30` | 15~30分钟常规 | 默认预选项；适配大多数日常下班备餐 |
| `t_60` | `60` | 30~60分钟从容 | 允许包含慢炖煲汤、烤箱烘焙菜式 |
| `t_unlimited` | `999` | 时间充裕不限 | 不以烹饪时长限制召回 |

---

## <a id="enum-usr-appliance"></a>7. `ENUM-USR-Appliance`（可用厨房厨具）

| 枚举编码 | 标准展示文案 | 默认选中态 | 业务判定语义 |
| :--- | :--- | :--- | :--- |
| `wok_pot` | 燃气灶/炒锅汤锅 | 默认必选 | 常规煎炒煮蒸基础设备 |
| `rice_cooker` | 电饭煲 | 默认选中 | 支撑一锅焖饭、预约煮粥 |
| `air_fryer` | 空气炸锅 | 未选中 | 解锁免油炸烤肉、烤时蔬菜谱 |
| `oven` | 烤箱 | 未选中 | 解锁烘焙与整烤大菜 |
| `microwave` | 微波炉 | 未选中 | 支持快手叮熟备菜与复热 |
| `pressure_cooker` | 电压力锅/高压锅 | 未选中 | 大幅缩短牛腩排骨炖煮时间提示 |
| `blender` | 破壁机/料理机 | 未选中 | 解锁浓汤、豆浆果昔类菜谱 |

---

## <a id="enum-usr-healthtag"></a>8. `ENUM-USR-HealthTag`（健康饮食偏好标签）

| 枚举编码 | 标准展示文案 | 业务判定语义（与菜谱健康标签双向对齐） |
| :--- | :--- | :--- |
| `balanced` | 均衡膳食 | 默认预选项；三大营养素比例均衡 |
| `low_calorie` | 减脂低卡 | 单人份主菜热量通常 `<= 350 kcal`、清淡控油 |
| `high_protein` | 高蛋白增肌 | 蛋白质供能比 `>= 25%` 或单份蛋白质 `>= 20g` |
| `low_gi` | 控糖低GI | 粗粮杂豆替代精制碳水、无额外添加白砂糖烹调 |
| `low_fat_salt` | 少油少盐 | 蒸煮白灼凉拌为主，低钠轻负担 |
| `stomach_friendly` | 温和养胃 | 温热软烂、免生冷刺激、易消化吸收 |
