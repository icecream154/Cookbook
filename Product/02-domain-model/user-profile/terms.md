# 用户与饮食画像域：业务术语表（`TERM-USR-*`）

| 术语 ID | 标准中文名 | 英文对照 | 严格业务定义 |
| :--- | :--- | :--- | :--- |
| <a id="term-usr-01"></a>**TERM-USR-01** | **饮食画像（饮食档案）** | Dietary Profile | 用户显式配置的用餐人数结构、口味偏好、辣度上限、忌口过敏源、厨艺水平、可用厨具、期望耗时、健康诉求与使用目的的结构化集合，用于驱动每日三餐推荐与详情页默认人数初始化。 |
| <a id="term-usr-02"></a>**TERM-USR-02** | **本地偏好草稿** | Local Profile Draft | 未登录游客通过偏好引导向导配置并暂存在客户端本地存储中的饮食画像数据；在未登录前可完全驱动本地个性化推荐，待用户完成认证后参与云端档案裁决合并。 |
| <a id="term-usr-03"></a>**TERM-USR-03** | **硬性饮食约束** | Hard Dietary Constraint | 饮食画像中具备“一票否决权”的子集，特指**忌口过敏食材**、**最高辣度上限**与**未拥有的必需厨具**；今日三餐自动推荐时不得以任何排序加分理由突破硬性饮食约束。 |
