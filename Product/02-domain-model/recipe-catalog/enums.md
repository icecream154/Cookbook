# 菜谱与标准食材域：标准枚举字典（`ENUM-RCP-*`）

## <a id="enum-rcp-cuisine"></a>1. `ENUM-RCP-Cuisine`（菜系分类）

| 枚举编码 | 标准展示文案 | 业务说明 |
| :--- | :--- | :--- |
| `homestyle` | 家常菜 | 国民高频日常快手炒炖菜 |
| `sichuan` | 川菜 | 麻辣、糊辣、荔枝口等巴蜀风味 |
| `cantonese` | 粤菜 | 清蒸、白灼、煲汤等鲜美原味 |
| `hunan` | 湘菜 | 香辣爆炒、锅气下饭菜 |
| `shandong` | 鲁菜 | 葱烧、酱爆等北方醇厚风味 |
| `jiangzhe` | 江浙菜 | 清鲜微甜、红烧糟卤江南风味 |
| `western` | 西式料理 | 三明治、意面、煎牛排等西式简餐 |
| `jp_kr` | 日韩料理 | 照烧、荞麦面、大酱汤等东亚简餐 |
| `light_salad` | 轻食沙拉 | 能量碗、低脂冷热沙拉 |
| `pastry_baking` | 烘焙面点 | 中西式面食早点与空气炸锅/烤箱烘焙 |

---

## <a id="enum-rcp-mealslot"></a>2. `ENUM-RCP-MealSlot`（每日餐次槽位）

| 枚举编码 | 标准展示文案 | 默认聚焦时段 |
| :--- | :--- | :--- |
| `breakfast` | 早餐 | `05:00 ~ 09:59` |
| `lunch` | 午餐 | `10:00 ~ 14:59` |
| `dinner` | 晚餐 | `15:00 ~ 21:59` |

---

## <a id="enum-rcp-dishrole"></a>3. `ENUM-RCP-DishRole`（菜品在套餐中的配餐角色）

| 枚举编码 | 标准展示角标 | 适用配餐槽位与职责 |
| :--- | :--- | :--- |
| `breakfast_main` | 主食早点 | 早餐核心碳水+蛋白主品（如滑蛋三明治、北非蛋吐司） |
| `one_bowl` | 一碗端 | 见 [TERM-RCP-03](./terms.md#term-rcp-03)，`1人食` 午晚餐首选独立成餐菜品 |
| `main_meat` | 主荤硬菜 | 2人及以上正餐的核心肉禽水产/下饭主菜 |
| `side_veg` | 清爽时蔬 | 2人及以上正餐搭配的快手绿叶菜/菌菇素菜 |
| `soup` | 汤羹粥品 | 早餐粥饮或三口及以上正餐的汤品槽位 |

---

## <a id="enum-rcp-spiciness"></a>4. `ENUM-RCP-Spiciness`（通用辣度分级）

> 同时被用户饮食画像 `max_spiciness` 与菜谱 `spiciness` 引用，保证数值可直接比大小。

| 枚举编码 / 数值 | 标准展示文案 | 代表菜谱标尺 |
| :--- | :--- | :--- |
| `0` | 不辣 | 清蒸鲈鱼、黄金番茄炒蛋（完全免辣椒素） |
| `1` | 微辣 | 家常宫保鸡丁、蒜香微辣排骨（轻微提香） |
| `2` | 中辣 | 牛肉末麻婆豆腐、农家小炒肉（明显辣感下饭） |
| `3` | 重辣 | 水煮肉片、尖椒兔（重油重辣无辣不欢） |

---

## <a id="enum-rcp-difficulty"></a>5. `ENUM-RCP-Difficulty`（菜谱烹饪难度）

| 枚举编码 | 标准展示文案 | 编撰评定客观准绳 |
| :--- | :--- | :--- |
| `easy` | 简单 | 工序 `<= 3` 步，无炒糖色/油炸复炸等易翻车火候考验 |
| `medium` | 适中 | 工序 `3 ~ 5` 步，涉及上浆、勾芡或慢炖火候转换 |
| `hard` | 挑战 | 工序 `> 5` 步或对刀工、油温控制有较高精准要求 |

---

## <a id="enum-rcp-scalemode"></a>6. `ENUM-RCP-ScaleMode`（食材换算取整模式）

| 枚举编码 | 适用计量单位示例 | 关联业务规则 |
| :--- | :--- | :--- |
| `weight_vol` | `g`, `ml` | 按阶梯粒度取整（详见 [RULE-COOK-02](../../03-business-rules/portion-and-cooking.md#rule-cook-02)） |
| `half_piece` | `个`, `片`, `块`, `颗` | 按 `0.5` 为最小刻度取整 |
| `whole_int` | `条`（整鱼）, `只`（整鸡）, `鸡蛋(个)` | 按 `>= 1` 的正整数取整，禁止拆出半条活鱼或半个生蛋 |
| `spoon_step` | `勺`, `茶匙` | 按 `0.5` 勺刻度取整 |
| `unscaled` | `少许`, `适量` | 保持原文本不参与数值乘法 |

---

## <a id="enum-rcp-heatlevel"></a>7. `ENUM-RCP-HeatLevel`（工序图表火力等级）

| 枚举数值 | 标准展示文案 | 时间轴图表视觉高度与语义 |
| :--- | :--- | :--- |
| `0` | 备菜无火 | 45% 高度 · 冷处理（洗切、抓腌、静置泡发） |
| `1` | 小火微沸 | 65% 高度 · 文火慢炖、推滑蛋、保温焖熟 |
| `2` | 中火煎炒 | 82% 高度 · 常规煸炒底料、双面煎熟 |
| `3` | 大火爆收 | 100% 高度 · 沸水焯烫、猛火快炒断生、大火收浓汤汁 |
