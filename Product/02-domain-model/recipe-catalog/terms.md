# 菜谱与标准食材域：业务术语表（`TERM-RCP-*`）

| 术语 ID | 标准中文名 | 英文对照 | 严格业务定义 |
| :--- | :--- | :--- | :--- |
| <a id="term-rcp-01"></a>**TERM-RCP-01** | **标准食材库** | Standard Ingredient Dictionary | 消除俗称差异的归一化食材主数据（例如用户搜索“西红柿”或“洋柿子”均归一映射至标准食材 `番茄`），同时承载食材采购分类与所属过敏忌口大类。 |
| <a id="term-rcp-02"></a>**TERM-RCP-02** | **基准人份** | Base Servings | 每道菜谱在编撰入库时设定的原始标准用餐人数（如红烧肉基准为 `3` 人份，滑蛋三明治基准为 `1` 人份）；一切动态分量折算均以 `目标人数 / 基准人份` 为缩放比例系数。 |
| <a id="term-rcp-03"></a>**TERM-RCP-03** | **一碗端** | One-Bowl Meal | 单道菜品内同时包含主食碳水、优质蛋白与膳食纤维蔬菜的综合餐食（如番茄肥牛焖饭、照烧鸡腿荞麦面碗），专为 `1人食` 场景设计以实现“做一道即成完整一餐”。 |
| <a id="term-rcp-04"></a>**TERM-RCP-04** | **步骤动态占位符** | Dynamic Step Token | 富文本做法步骤正文中通过结构化标记（如 `{ing_soy_sauce}`）对当前菜谱食材表条目的引用；当用户在详情页调整用餐人数时，正文中内嵌的调料/主料用量随之同步实时重算，杜绝图文克数不一致。 |
