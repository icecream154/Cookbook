# 膳食规划与收藏域：业务术语表（`TERM-PLN-*`）

| 术语 ID | 标准中文名 | 英文对照 | 严格业务定义 |
| :--- | :--- | :--- | :--- |
| <a id="term-pln-01"></a>**TERM-PLN-01** | **餐次套餐结构** | Meal Composition | 根据当前生效的用餐人数档位（`household_size`），为每日早、午、晚各餐次确定的配餐角色槽位集合（如三口之家正餐固定由 `1 主荤 + 1 时蔬 + 1 汤羹` 三个槽位构成）。 |
| <a id="term-pln-02"></a>**TERM-PLN-02** | **同餐主材互斥** | Intra-Meal Ingredient Mutex | 同一餐次（如午餐）内的多道推荐菜品之间，其第一主食材（`primary_main_ing_id`）不得重复的配餐约束，防止出现同桌既有“番茄炒蛋”又有“番茄滑蛋汤”的配菜雷同。 |
| <a id="term-pln-03"></a>**TERM-PLN-03** | **画像待刷新态** | Profile Dirty State | 当日三餐方案已经生成后，用户在个人中心修改并保存了饮食档案时触发的挂起状态；系统通过非侵入式确认条询问用户“立即重算今日菜单”还是“保留今日原菜单、明日再生效”，防止静默覆盖用户已买好菜的菜单。 |
